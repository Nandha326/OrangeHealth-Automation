===========================================================
 OrangeHealth Automation - Test Execution Commands
===========================================================

-----------------------------------------------------------
 Full Suite
-----------------------------------------------------------

mvn clean test


-----------------------------------------------------------
 By Suite-Level Tags
-----------------------------------------------------------

# All Smoke tests (all 3 features)
mvn clean test "-Dcucumber.filter.tags=@Smoke"

# All Regression tests
mvn clean test "-Dcucumber.filter.tags=@Regression"


-----------------------------------------------------------
 Individual Feature Pages
-----------------------------------------------------------

# HomePage
mvn clean test "-Dcucumber.filter.tags=@HomePage"

# HealthCheckup
mvn clean test "-Dcucumber.filter.tags=@HealthCheckup"

# Tests Page
mvn clean test "-Dcucumber.filter.tags=@Tests"


-----------------------------------------------------------
 Scenario-Level Tags
-----------------------------------------------------------

# Search & Booking scenario only
mvn clean test "-Dcucumber.filter.tags=@Search and @Booking"


-----------------------------------------------------------
 Useful Combinations
-----------------------------------------------------------

# Headless run (full suite)
mvn clean test "-Dcucumber.filter.tags=@Smoke" "-Dheadless=true"

# Specific feature + headless
mvn clean test "-Dcucumber.filter.tags=@HomePage" "-Dheadless=true"

# Exclude a tag
mvn clean test "-Dcucumber.filter.tags=@Regression and not @HomePage"


-----------------------------------------------------------
 Cross-Browser Testing Suite (All Modules - Two Browsers Simultaneously)
-----------------------------------------------------------

# Run Cross-Browser Suite (Default: Chrome and Firefox in parallel):
mvn clean test -Pcrossbrowser

# Run Cross-Browser Suite (Custom browsers: e.g. Chrome and Edge in parallel):
mvn clean test -Pcrossbrowser "-Dbrowser1=chrome" "-Dbrowser2=edge"

# Run Cross-Browser Suite in Headless Mode:
mvn clean test -Pcrossbrowser "-Dheadless=true"

# Run Specific Tags across both browsers (e.g., @Smoke or @Regression):
mvn clean test -Pcrossbrowser "-Dcucumber.filter.tags=@Smoke" "-Dbrowser1=chrome" "-Dbrowser2=firefox"

# PowerShell Helper Script (Default: Chrome and Firefox):
.\run-tests.ps1 -suiteXml "testng-crossbrowser.xml" -tags "@Smoke"

# PowerShell Helper Script with custom browsers:
.\run-tests.ps1 -suiteXml "testng-crossbrowser.xml" -browser1 chrome -browser2 edge -tags "@Smoke"


-----------------------------------------------------------
 Reports Generated
-----------------------------------------------------------

- Standard Suite Extent Report     : reports/ExtentReport_<timestamp>.html
- Cross-Browser Suite Extent Report: reports/ExtentReport_CrossBrowser_<timestamp>.html
- Cucumber HTML Report             : target/cucumber-reports/crossbrowser-report.html


-----------------------------------------------------------
 Notes
-----------------------------------------------------------

- -Pcrossbrowser                        : Maven profile for cross-browser suite
- "-DsuiteXmlFile=testng-crossbrowser.xml" : Executes cross-browser suite (quote for PowerShell)
- -Dheadless=true                       : Runs browsers in headless mode
- -Dbrowser=chrome|edge|firefox         : Override browser for single-run suite
- System properties (-D) override config.properties values
