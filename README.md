# OrangeHealth Automation Framework

This is the initial enterprise scaffold for a Hybrid BDD Automation Framework.

## Planned Stack
- Java
- Selenium WebDriver
- Cucumber BDD
- TestNG
- Maven
- Extent Reports
- Page Object Model

## Planned Modules
- Authentication
- Test Search
- Booking
- Payments
- Reports

This scaffold is intended as the foundation for a production-grade framework.
